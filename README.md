# 心蕊 AIRI

面向成年人的本地情绪支持工具。心蕊用温柔的角色陪伴用户缓解情绪内耗、压力和求助困难。

## 当前功能

- Live2D 心蕊角色与动作
- 昵称进入和本地档案
- 四个情绪支持入口
- 五分钟情绪稳定流程
- 内耗拆解、压力拆解和两分钟小行动
- 求助消息生成与复制
- 中国大陆场景的安全计划
- 本地记忆查看、删除和清除
- 安静模式
- 无 API 时的本地规则回退

## 运行

```bash
npm install
PORT=3000 node server.js
```

浏览器打开 `http://localhost:3000`。产品托管时使用 `app.toml`，服务会从 `$PORT` 读取端口并绑定 `0.0.0.0`。

## 可选模型接口

设置 OpenAI 兼容接口即可启用模型增强回复：

```bash
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=your-key
OPENAI_MODEL=gpt-4.1-mini
```

没有 API 时仍可使用本地情绪流程。密钥不要写入代码或提交到仓库。

## 定位与安全边界

心蕊是情绪支持和自助整理工具，不是医生，不能替代心理咨询、精神科治疗或紧急救援。出现立即危险时，请联系身边可信任的人，去有人在的地方，拨打 `120` 或 `110`，或前往附近医院急诊。
