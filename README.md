# 心蕊 AIRI

面向成年人的本地情绪支持工具。心蕊用温柔的角色陪伴用户缓解情绪内耗、压力和求助困难。

## 当前功能

- Live2D 心蕊角色与动作
- 昵称进入和本地档案
- 每日心情、精力、压力和陪伴偏好的轻量状态记录
- 根据当日状态和对话内容变化的动态工具推荐
- 五分钟情绪稳定流程
- 内耗拆解、压力三栏分类、现实问题解决和两分钟小行动
- 可选择“下次回来问我”的行动回访
- 带分类和效果反馈的个人舒缓工具箱
- 求助消息生成与复制
- 包含预警信号、安定方式、安全地点、联系人和专业支持的安全计划
- 最近 20 轮对话本地保存、恢复和单独清空
- 长期记忆、有效方法、行动回访和最近对话分区管理
- OpenAI 兼容模型的多轮陪伴回复
- SSE 流式显示与模型失败本地降级
- 安静模式
- 无 API 时的本地规则回退

## 运行

```bash
npm install
PORT=3000 node server.js
```

浏览器打开 `http://localhost:3000`。产品托管时使用 `app.toml`，服务会从 `$PORT` 读取端口并绑定 `0.0.0.0`。

## 可选模型接口

设置 OpenAI 兼容接口即可启用模型增强回复：

```bash
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=your-key
OPENAI_MODEL=gpt-4.1-mini
OPENAI_TIMEOUT_MS=30000
```

没有 API 时仍可使用本地情绪流程。密钥由服务端环境变量管理，不会发送给浏览器；不要把密钥写入代码或提交到仓库。

## 数据与上下文

- 服务端不保存聊天内容。
- 最近 20 轮对话保存在当前浏览器的 `localStorage`，用于恢复界面；每次最多向模型发送最近 12 轮。
- 只有用户主动添加的长期记忆，以及未标记为“不适合”的有效方法，才作为个人背景传给模型。
- 今日状态、舒缓方法、行动回访和安全计划均保存在当前浏览器中，可逐项删除或整体清除。
- 用户可单独清空最近对话，也可清除当前昵称的全部本地记录。

## 代码结构

```text
src/
  agent.js                         # 会话编排、模型降级和结构化提取
  character.js                     # 固定心蕊人格与上下文压缩
  knot.js                          # 本地心结和情绪工具
  safety.js                        # 模型调用前的安全判断
  providers/openai-compatible.js   # OpenAI 兼容接口与流式解析
```

`/api/chat` 默认返回 JSON；请求头包含 `Accept: text/event-stream` 或请求体设置 `stream: true` 时返回 SSE。

## 定位与安全边界

心蕊是情绪支持和自助整理工具，不是医生，不能替代心理咨询、精神科治疗或紧急救援。出现立即危险时，请联系身边可信任的人，去有人在的地方，拨打 `120` 或 `110`，或前往附近医院急诊。

危机判断在模型调用前执行，模型不能覆盖或绕过危机回复。
